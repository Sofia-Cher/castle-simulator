# castle-simulator

Курсовой проект: симулятор средневекового замка с экономикой и осадами
на консольном интерфейсе.

## Тема

Симуляция жизни средневекового замка: экономика (ресурсы, налоги, торговля),
строительство, население, армия и осады. Пользователь управляет замком
через консольное меню.

## Языки реализации

- C++ — основная логика (ядро симуляции, экономика, осады).
- Java — модуль дополнительных расчётов и визуализации данных.

## Структура репозитория

castle-simulator/
  README.md          — описание проекта
  .gitignore         — правила игнорирования для C++ и Java
  cpp/               — исходники на C++
    src/             — .cpp файлы
    include/         — .h файлы
  java/              — исходники на Java
    src/             — .java файлы
  docs/              — документация
    domain.md        — описание предметной области
  assets/            — диаграммы, схемы

## Сборка

Команды сборки будут добавлены по мере появления кода.

C++:
  cd cpp
  g++ src/*.cpp -o castle-simulator
  ./castle-simulator

Java:
  cd java
  javac src/*.java -d out
  java -cp out Main
